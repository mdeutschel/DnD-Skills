# Charakterbogen-Checkliste

Was muss auf einem konsistenten Bogen stehen, was wird oft vergessen. Für die Erstellung **und** für jeden Stufenaufstieg. Vor dem Tisch durchgehen, nicht währenddessen.

## Kopfbereich

- [ ] Name, Klasse, Stufe, Subklasse (ab Stufe 3), Hintergrund, Spezies, Gesinnung
- [ ] EP (aktuell), nächster EP-Schwellwert (siehe `stufenaufstieg.md`)
- [ ] Übungsbonus (passend zur Stufe: +2 bis 4, +3 bis 8, +4 bis 12, +5 bis 16, +6 ab 17)
- [ ] Inspiration-Marker (falls am Tisch genutzt)

## Attribute und Modifikatoren

- [ ] Sechs Attribute mit aktuellem Wert (nach Hintergrund-Boni und allen Erhöhungen)
- [ ] Modifikatoren neben jedem Attribut

## Rettungswürfe

- [ ] Welche zwei Attribute Klassen-Übung haben (Häkchen sichtbar)
- [ ] Bonus = Attribut-Mod + Übungsbonus (falls Übung)
- [ ] Sonderfälle: Talent „Resilient" (Übung in einer weiteren Rettung), Magisches Item, Klassen-Bonus (z. B. Paladin-Aura)

## Fertigkeiten

- [ ] Alle 18 Fertigkeiten mit Mod
- [ ] Übungen markiert (Häkchen sichtbar)
- [ ] Expertise markiert (doppelter Übungsbonus, z. B. Schurke, Barde)
- [ ] Sonderboni notiert (Talent Skill Expert, Item-Boni)

## Kampf-Werte

- [ ] **Rüstungsklasse** (mit Schild eingerechnet wenn getragen)
- [ ] **Initiative** (GES-Mod + Klassen/Talent-Boni — z. B. Alert-Talent: +Übungsbonus)
- [ ] **Geschwindigkeit** (Spezies-Wert, ggf. Klassen-Bonus z. B. Mönch, Barbar)
- [ ] **Trefferpunkte:** Max, aktuell, temporäre
- [ ] **Trefferwürfel-Vorrat:** Typ (W6/W8/W10/W12), Anzahl (= Stufe minus verbraucht)
- [ ] **Todesrettungswurf-Felder** (3 Erfolge, 3 Fehlschläge)
- [ ] **Passive Wahrnehmung** (10 + WEI-Mod + Übung)
- [ ] Weitere passive Werte falls relevant: Untersuchung, Einsicht

## Angriffe

Pro Waffe:

- [ ] Name
- [ ] Angriffsbonus (Übungsbonus + STÄ-Mod oder GES-Mod je nach Finesse/Range)
- [ ] Schaden (Würfel + Mod, Schadensart)
- [ ] **Waffenbeherrschungs-Eigenschaft** (siehe `waffenbeherrschung.md`) — pro Waffe genau eine, je nach Klasse 2–3 gleichzeitig nutzbar
- [ ] Reichweite (Nahkampf 1,5 m oder Reichweite; Fernkampf normale/lange)
- [ ] Eigenschaften (Finesse, Zwei­handlig, Vielseitig, Schwer, Leicht, etc.)

## Zauber (falls Caster)

- [ ] Zauber-Attribut (INT/WEI/CHA je nach Klasse)
- [ ] **Zauber-SG** = 8 + Übungsbonus + Zauber-Mod
- [ ] **Zauber-Angriffsbonus** = Übungsbonus + Zauber-Mod
- [ ] Bekannte/vorbereitete Cantrips
- [ ] Bekannte/vorbereitete Zauber pro Slot-Stufe
- [ ] Slot-Vorrat pro Stufe (markierbare Kästchen für Verbrauch)
- [ ] Konzentration-Marker (was läuft gerade)
- [ ] Komponenten-Pouch oder Zauberfokus dabei?
- [ ] Klassen-spezifisch: Sorcery Points, Bardische Inspiration, Pact-Slots (kurze-Rast-Refresh), Channel Divinity (Counter), Lay on Hands-Pool, Wild-Shape-Counter, Hunter's Mark-Status

## Klassen-Features

- [ ] Alle Stufe-1-bis-aktuelle-Stufe-Features eingetragen
- [ ] Auswahlen getroffen (Kampfstil, Subklassen-Spezialisierungen, Metamagie, Invocations, Cantrip-Upgrades)
- [ ] Verbrauchsbare Klassen-Ressourcen mit Counter (Aktions-Schub, Indomitable-Use, Channel Divinity, Wut-Verbrauch)
- [ ] Pro-Rast-Resets klar markiert: kurze Rast (sr) vs. lange Rast (lr)

## Spezies und Hintergrund

- [ ] Spezies-Merkmale eingetragen (Dunkelsicht, Drachen-Atemwaffe-Verbrauch, Halbling-Glück-Marker, etc.)
- [ ] Hintergrund-Talent eingetragen, Effekt verstanden
- [ ] Hintergrund-Fertigkeiten und Werkzeug-Übung markiert

## Ausrüstung

- [ ] Rüstung mit aktuellem Status (intakt, beschädigt)
- [ ] Waffen mit Mastery-Eigenschaft notiert
- [ ] Schild ja/nein
- [ ] Reise-Equipment, Werkzeuge, Heiltränke
- [ ] Gold/Silber/Kupfer aktueller Stand
- [ ] Magische Gegenstände (Wirkung, Anzahl Ladungen, Eingestimmt ja/nein)
- [ ] Tragelast (oft ignoriert, manche GMs setzen es durch — Stärke-Score × 7,5 kg)

## Charakter-Inhalt

- [ ] Bindung, Wunde, Ziel (siehe `spieler-anker.md`)
- [ ] Persönlichkeitszüge, Ideale, Bindungen, Makel (PHB-Format) — optional aber hilfreich
- [ ] Aussehen kurz notiert
- [ ] Hintergrundgeschichte als Schlagwort-Liste, nicht als Roman

## Konsistenzprüfung beim Stufenaufstieg

Beim Aufstieg von n → n+1 explizit durchgehen:

1. **Übungsbonus erhöht?** (Auf Stufe 5, 9, 13, 17 jeweils +1 — alle Werte mit Übung neu rechnen.)
2. **TP korrekt?** (Fixer Wert oder Wurf + KON-Mod; bei KON-Erhöhung +1 TP pro Stufe rückwirkend.)
3. **Trefferwürfel-Vorrat um 1 erhöht?**
4. **Neue Klassenmerkmale eingetragen?**
5. **Auswahlen aus neuen Features getroffen?**
6. **Subklassen-Merkmale ergänzt (Stufen 3, 6, 10, 14)?**
7. **Bei Stufen 4, 8, 12, 16, 19: Talent oder Attribut-Erhöhung getroffen?**
8. **Caster: neue Slots, neue gelernte/vorbereitete Zauber?**
9. **Zauber-SG und Zauber-Angriffsbonus nachgerechnet?**

## Häufig vergessen

- **Mastery-Eigenschaften** pro Waffe (mehr als die Hälfte aller Bögen lässt sie weg).
- **Passive Wahrnehmung** (wird ständig gebraucht, oft nicht auf dem Bogen).
- **Initiative-Boni** über GES hinaus (Alert-Talent, Klassen-Features).
- **Konzentrations-Slots** (welche Zauber blockieren sich gegenseitig?).
- **Trefferwürfel-Vorrat** (wird bei kurzer Rast verbraucht — leicht zu vergessen).
- **Komponenten-Pouch** oder Zauberfokus (kein Pouch → V/G/M-Verbalkomponenten gehen, aber materielle ohne Goldwert nicht).
- **Talent-Effekte** verbal nachgelesen (steht oft nur der Talent-Name auf dem Bogen).
- **Bonus-Aktions-Optionen** (Lay on Hands, Heimtückischer Angriff per Bonus-Heimlichkeit, Mönchs-Schlag).
- **Reaktions-Optionen** (Wachsamer Verteidiger, Schurken-Ausweichen, Shield-Zauber, Opportunity Attack).
